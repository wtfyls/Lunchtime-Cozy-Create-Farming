# Lunchtime

**A cozy Minecraft modpack built around cooking, farming, building, Create automation, and exploration.**

Lunchtime is a curated modpack for relaxed solo and multiplayer play, with cozy building, food, automation, quests, and exploration. This repository is the home for project documentation, release history, and development notes.

## Reporting issues

Before reporting a bug, search existing issues and include the Lunchtime version, Minecraft/Forge version, steps to reproduce, and a relevant sanitized log or crash report. Never post passwords, tokens, or private server details.

Use GitHub Issues for reproducible bugs and feature suggestions. For player-to-player help, use the official Discord once its invite is added above.
