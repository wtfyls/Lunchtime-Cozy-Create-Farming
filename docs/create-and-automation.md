# Create and Automation

Create gives Lunchtime a way to turn simple resources and clever designs into moving machines. You can build by hand, automate one task at a time, and expand only when you need more output.

## Start small

A good first automation project should solve a problem you already have. Choose a repeated task, identify the recipe or processing step, and look for a Create component that can do part of the work.

Before building a large production line:

1. Look up the output item in the recipe viewer.
2. Confirm which machine or processing step is required.
3. Test the smallest working version.
4. Add item transport, storage, and input handling after the core process works.
5. Expand the build only when you know what limits its output.

## Create and cooking

Lunchtime includes Create integrations for food processing, including Create: Slice & Dice and Create: Central Kitchen in the project mod list. These systems connect mechanical automation with supported cooking recipes. Use the recipe viewer to confirm which food recipes can be automated and how they are processed in your current release.

## Make builds look like they belong

Create: Copycats+ adds ways to use the appearance of other blocks within Create builds, helping contraptions fit a cottage, workshop, kitchen, or factory. Keep belts, shafts, and moving blocks accessible while leaving room to decorate around the machine.

## Design for multiplayer and performance

- Keep moving parts and storage organized so other players can understand the system.
- Leave walking space and access to controls.
- Avoid making every machine run continuously if it does not need to.
- If a server develops tick lag, test with fewer active machines and profile the server rather than guessing.
- Use the [Performance Guide](performance.md) for server and profiling advice.

The point is to make work more interesting, not to require a huge factory for every recipe.
