# Getting Started

Welcome to Lunchtime! You do not need to learn every mod before you begin. Start small, explore the questbook, and let your world develop naturally.

## 1. Install the pack

1. Open the [Lunchtime CurseForge page](https://www.curseforge.com/minecraft/modpacks/lunch-but).
2. Install the latest release offered there using a supported Minecraft launcher.
3. Let the launcher download the pack and its dependencies.
4. Start the game and allow the first launch to finish. Large modpacks can take longer to load, especially after an update.

Lunchtime's current development setup targets **Minecraft 1.20.1, Forge 47.4.28, and Java 17**. Always check the CurseForge release details and install the matching pack version.

## 2. Give Minecraft enough memory

For this large pack, **8 GB allocated to the Minecraft client is a reasonable starting point** if your computer has enough total RAM. Do not allocate all system memory to Minecraft. More RAM is not automatically better.

For more settings and troubleshooting, see the [Performance Guide](performance.md).

## 3. Create a world

Create a new world for the smoothest start with the current world-generation setup. If you already have a Lunchtime world, back it up before updating the pack; never delete a save just to troubleshoot a problem.

When you spawn in, take a moment to gather basic supplies, find a place to settle, and collect seeds and food. A small starter farm and a protected storage area make later projects much easier.

## 4. Open the questbook

Lunchtime uses **FTB Quests** to introduce systems and give you goals to work toward. Start with the Lunchtime/welcome quests, then follow whichever branches interest you. You do not have to complete every chapter in order to enjoy the pack.

Some quest titles, requirements, and rewards may change as the pack develops. Check the questbook in your installed version for the exact current details.

See [Quests and Progression](quests-and-progression.md) for more.

## 5. Learn recipes as you go

Use the recipe viewer included with the pack to search for items and inspect recipes. When you find an ingredient, machine, or block you do not recognize, look it up before crafting a pile of materials.

For multi-step recipes, check both the recipe and the machine or workstation that performs it. Some automation paths combine Create with food-processing systems.

## 6. Choose a first project

Try one of these goals:

- Build a little home with storage, beds, lighting, and a cooking area.
- Start a garden and learn a few recipes from your harvest.
- Follow the Create quests and build a small machine that solves one repetitive task.
- Explore nearby terrain and bring back useful materials for your base.
- Play with friends and divide up farming, building, cooking, and automation projects.

## If the game does not launch

First, confirm that the launcher installed the intended Lunchtime release and that you have not added extra mods. Then read the [Performance and Troubleshooting Guide](performance.md). For a reproducible pack bug, use [GitHub Issues](ISSUE_TRIAGE.md); for general gameplay questions, ask in [Discord](https://discord.gg/68yhDdFpnx).
