# Quests and Progression

Lunchtime uses **FTB Quests** to guide players through the pack, explain major systems, and provide goals for solo worlds and multiplayer groups.

Think of the questbook as a guide, not a strict checklist. It is fine to pause a questline to build a house, try a new recipe, or explore with friends.

## How to use the questbook

1. Open the in-game questbook interface.
2. Start with the Lunchtime or welcome section if you are new.
3. Read the quest description before gathering ingredients or building a machine.
4. Follow the required task or tasks and claim the reward when the quest allows it.
5. Use the questbook to find a new goal when you are not sure what to try next.

The exact interface, chapter names, dependencies, and reward rules can change between pack versions. Use the questbook in your installed build as the final authority.

## What kinds of goals should you expect?

### Lunchtime basics
Get comfortable with the pack, learn the core tools, and establish a base to build from.

### Farming and cooking
Grow ingredients, learn the food systems, and discover recipes that make your farm and kitchen useful.

### Create and automation
Progress from basic components into contraptions and more involved production setups. Start with a machine that solves one small problem before scaling it up.

### Exploration and discoveries
Use exploration quests as a reason to leave home, collect unfamiliar materials, and investigate new locations. Some content is tied to specific mods, so read the current quest requirements carefully.

### Collections and optional goals
Some branches may focus on collecting themed items and decorations, including plushie-related content. Check your release's questbook for the exact items, unlock conditions, and rewards.

## Playing as a group

On a shared world, decide together whether to focus on different branches or work through the same goals. Farming, cooking, building, storage, and Create production work well as team projects. Agree on shared storage and machine areas before building a large factory in the middle of someone's home.

## A quest does not complete

- Re-read the task description; some tasks require crafting, holding, visiting, or interacting with something specific.
- Check that you are using the correct item or recipe from the current pack.
- Look for any prerequisite quest that must be completed first.
- Check whether the task is intended to be shared or individual in multiplayer.
- If the task still appears broken, search existing [GitHub issues](https://github.com/wtfyls/Lunchtime-Cozy-Create-Farming/issues) before reporting it.

When reporting a quest bug, include the Lunchtime version, quest chapter/title, what you did, what you expected, and a screenshot if useful.
