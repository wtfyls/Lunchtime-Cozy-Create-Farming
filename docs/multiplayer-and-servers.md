# Multiplayer and Servers

Lunchtime is designed for shared projects as well as solo worlds. A good server gives players room to build their own homes while making cooperation easy.

## Before joining or hosting

- Make sure everyone is using the same Lunchtime release.
- For a dedicated server, use server files and instructions intended for the matching release.
- Do not assume a client-only mod can be copied to a dedicated server; follow the pack's server guidance.
- Back up the world before updating the server or changing world-generation content.

## Make a shared world easier to live in

Agree on a few basics before the world gets busy:

- Decide which area is spawn and which areas are available for personal builds.
- Label shared storage and avoid taking the last of a resource without telling the group.
- Plan shared Create factories and farms with enough space for maintenance and expansion.
- Consider splitting up responsibilities—such as farming, cooking, building, exploring, and automation—without forcing anyone to play only one way.

## Claims and teams

The pack's multiplayer tooling may provide team and chunk-management features depending on the current release and server configuration. Use the in-game interface and server rules to confirm which protections are active. Do not assume a claim protects a build until you can verify it in your server.

## Performance on a server

Large farms, moving Create contraptions, many entities, and new chunk generation can all affect performance. If a server slows down, collect the relevant timings or a spark profile while the problem is happening. See the [Performance Guide](performance.md).
