# The Lunchtime Mod List

Lunchtime is a large modpack with content, quality-of-life improvements, building tools, multiplayer utilities, and optimization mods. This page introduces the main categories; the full list below is generated from the repository's maintained master list during the website build.

## Main categories

- **Performance and optimization:** tools aimed at memory use, loading, rendering, world generation, and server profiling.
- **Create and automation:** Create and supporting integrations for mechanical builds and processing.
- **Farming, cooking, and food:** crops, ingredients, food preparation, and cooking-related additions.
- **World generation and exploration:** new places, structures, biomes, and exploration content.
- **Mobs, bosses, and combat:** creatures and optional adventure encounters.
- **Building, decoration, and furniture:** block palettes, decorative pieces, furniture, and creative building tools.
- **Quests, progression, and economy:** guidance, progression systems, and multiplayer-oriented gameplay.
- **Multiplayer and server tools:** utilities used to support group play and server administration.
- **Interface, visuals, and audio:** interface enhancements, visual features, and sound.
- **Quality of life, inventory, and recipe tools:** item management, recipe lookup, and usability improvements.
