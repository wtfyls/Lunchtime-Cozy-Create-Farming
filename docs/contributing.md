# Contributing to Lunchtime

Thanks for helping improve Lunchtime!

## What we welcome

- Reproducible bug reports and compatibility findings
- Feature, mod, quest, recipe, and progression suggestions
- Documentation improvements
- Tested configuration, quest, recipe, and localization fixes
- Performance reports backed by logs or repeatable measurements

## Where to report things

- **A bug or broken feature:** open a GitHub Issue using the Bug report form.
- **An idea or proposed improvement:** use the Feature request form.
- **A gameplay question or quick player-support request:** ask in the [Lunchtime Discord](https://discord.gg/68yhDdFpnx).
- **Private information or sensitive reports:** do not post them publicly; contact a maintainer privately.

Read [Issue Triage](ISSUE_TRIAGE.md) for what happens after a ticket is submitted.

## Mod suggestions

Please include the official project link, exact Minecraft/loader compatibility, client/server requirements, what the mod adds, overlap with existing mods, and known performance or licensing concerns. A suggestion is not a promise that the mod will be added.

## Before submitting a change

- Search existing issues first.
- Keep each pull request focused on one change.
- Explain why the change is needed and how you tested it.
- Consider multiplayer behavior, progression, accessibility, performance, compatibility, and licensing.
- Update documentation or the changelog when appropriate.
- Do not upload mod JARs, copyrighted assets, secrets, or private player/server information unless there's a clear need and permission.

Maintainers may ask for more information or close proposals that duplicate existing work, cannot be tested, conflict with the pack's direction, or create unacceptable compatibility or performance risks.
