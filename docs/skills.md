# Skills and Specialization

Lunchtime is moving away from the old Jobs+ setup toward **Pufferfish's Skills** as the framework for player specialization.

> **Development note:** The Lunchtime skill trees and progression rules are being configured. The available categories, experience sources, unlocks, and rewards are not documented as final until they are shipped and verified in a release. Use this page as an overview, not a promise that every planned skill is already live.

## How the system works

Pufferfish's Skills is a configurable framework. The framework itself does **not** supply Lunchtime's finished skill tree; the pack also needs its own skill-tree data and configuration.

The intended direction is to reward players for the activities they enjoy and let groups develop different strengths, without making routine cozy play feel like a grind. The final details should explain:

- Which skill categories are available.
- How each category gains experience or skill points.
- What individual unlocks do.
- Whether any unlocks have prerequisites.
- How skills behave in multiplayer and whether progress is shared or personal.

These details will be added once the actual Lunchtime configuration is finalized and tested.

## I installed the pack but cannot see skills

First, check that you are using a release that includes the completed Lunchtime skill-tree data. Having the Pufferfish's Skills mod installed alone may not produce visible skill categories.

If skills are missing from a release that is supposed to include them, report the pack version and whether you are in single-player or on a server through [GitHub Issues](https://github.com/wtfyls/Lunchtime-Cozy-Create-Farming/issues). Do not install a random skill-tree datapack into the pack as a workaround; it may add unrelated balance or compatibility changes.
