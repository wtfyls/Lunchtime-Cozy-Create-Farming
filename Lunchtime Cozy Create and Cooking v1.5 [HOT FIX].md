# Lunchtime 1.5 — Hotfix

### Removed
• Removed **Ecliptic Seasons and its addons** due to excessive CPU usage. Performance is more important than seasonal effects for Lunchtime's cozy gameplay.

### Fixed
• Fixed connected-texture issues for a more consistent visual experience.
• Removed custom audio from **Streams Reflowing** to fix an audio bug.

### Changes
• Updated **PatPat** keybinds: main keybind changed to **Shift**, secondary keybind changed to **Mouse Button** for easier use and fewer keybind conflicts.
