# Changelog

All Lunchtime release notes live in this file, with the newest release first.

---

## v2

### Added
- Replaced Jobs+ and Jobs+ Tools with **Pufferfish’s Skills**, introducing a configurable skill system. All current skills are working.
- Re-added **Tom’s Simple Storage**, including its quests.
- Added **Spelunkery quests** to guide players through its underground progression.
- Added **Lunch Worlds**.
- Added **Stack Refill** for a smoother building and farming experience.
- Added **Gravestone x Curios API Compat**.
- Added **Create Liquid Fuel**.
- Added **Trample No More** to prevent accidental farmland trampling.
- Imported additional quests and improved existing progression.

### Changed
- Replaced **Easy Gen** with **Create Cobblestone**.

### Fixed
- Fixed water functionality to restore expected behavior.

### Removed
- Removed **Visual Workbench** due to a rendering issue.
- Removed **Better Days** as we move toward handling longer days through **Gentle Seasons**.
- Removed **Dynamic FPS** during the client-side cleanup.
- Removed **Streams Reflowing** during the world-generation and optimization review.

---

## 1.5 — Hotfix

### Removed
- Removed **Ecliptic Seasons and its add-ons** due to excessive CPU usage. Performance takes priority over seasonal effects for Lunchtime's cozy gameplay.

### Fixed
- Fixed connected-texture issues.
- Removed custom audio from **Streams Reflowing** to resolve an audio bug.

### Changed
- Updated **PatPat** keybinds: the main keybind is now **Shift**, and the secondary keybind is now **Mouse Button**, making it easier to use and helping avoid keybind conflicts.
