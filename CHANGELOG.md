# Changelog

All Lunchtime release notes live in this file, with the newest release first.

---

## 1.5 — Hotfix

### Removed
- Removed **Ecliptic Seasons and its add-ons** due to excessive CPU usage. Performance takes priority over seasonal effects for Lunchtime's cozy gameplay.

### Fixed
- Fixed connected-texture issues.
- Removed custom audio from **Streams Reflowing** to resolve an audio bug.

### Changed
- Updated **PatPat** keybinds: the main keybind is now **Shift**, and the secondary keybind is now **Mouse Button**, making it easier to use and helping avoid keybind conflicts.
